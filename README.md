# Cedomis Airdrop

Simple landing page for the Cedomis airdrop — black & red theme with the Cedomis logo and **“airdrop claim begins soon”** headline.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```
